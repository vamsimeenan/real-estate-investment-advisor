# 🏡 Real Estate Investment Advisor

## 📌 Overview
The Real Estate Investment Advisor is a data-driven analytics project that helps evaluate property investments using rule-based analytics and statistical methods. It analyzes real estate data to classify investment quality and forecast future property prices.

---

## 🚀 Features
- 📊 Data cleaning and preprocessing in Google Colab  
- 🔍 Exploratory Data Analysis (EDA) for insights  
- 🧠 Feature engineering (Price per Sqft, Appreciation Rate, etc.)  
- 📈 5-year property price forecasting using CAGR model  
- 🏷️ Rule-based investment classification (Good / Average / Poor)  
- 🌐 Interactive Streamlit web application  

---

## 🛠️ Tech Stack
- Python 🐍  
- Pandas, NumPy 📊  
- Matplotlib, Seaborn 📉  
- Scikit-learn 🤖  
- Streamlit 🌐  
- Google Colab 📓  

---

## 📊 Feature Engineering
- Price per square foot  
- Location-based value estimation  
- Appreciation rate calculation  
- Investment scoring system  
- CAGR-based future price prediction  

---

## 💡 Working Flow
1. Load and clean dataset  
2. Perform EDA (visual + statistical analysis)  
3. Engineer financial features  
4. Apply rule-based investment logic  
5. Predict 5-year property price using CAGR  
6. Display results in Streamlit dashboard  

---

## 📈 Output
- Investment classification (Buy / Hold / Avoid)  
- Predicted future property value  
- Market trend insights  
- Visual analytics dashboard
