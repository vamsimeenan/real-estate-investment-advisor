## 📌 Overview

**Real Estate Investment Advisor** is an intelligent analytics platform that evaluates property investment opportunities using **statistical analysis**, **financial feature engineering**, **CAGR-based forecasting**, and **rule-based investment scoring** — all surfaced through a clean, interactive Streamlit dashboard.

Evaluating real estate manually is time-consuming, data-intensive, and hard to forecast accurately. This system automates the entire pipeline from raw data to actionable investment decisions.

---

## ✨ Features

| Feature | Description |
|---|---|
| 📊 Exploratory Data Analysis | Visual and statistical insights on real estate datasets |
| 🧠 Financial Feature Engineering | Price/sqft, appreciation rate, location-based valuation |
| 📈 5-Year Price Forecasting | CAGR-based model to predict future property prices |
| 🏷️ Investment Classification | Auto-classify properties as **Buy**, **Hold**, or **Avoid** |
| 🌐 Interactive Dashboard | Clean Streamlit app for end-to-end property analysis |
| 📉 Visual Market Insights | Charts and trend visualizations for informed decisions |

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/vamsimeenan/real-estate-investment-advisor.git
cd real-estate-investment-advisor

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate        # Mac/Linux
# venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the dashboard
streamlit run app.py
```
