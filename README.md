# 🌟 Introduction

Real Estate Investment Advisor is an intelligent analytics platform designed to evaluate real estate investment opportunities using statistical analysis, financial forecasting, and rule-based investment scoring.

The project leverages:
- **Data Analytics**
- **Machine Learning**
- **Financial Forecasting**
- **Feature Engineering**
- **Interactive Visualization**

to help users make informed real estate investment decisions.

This project demonstrates:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Financial Feature Engineering
- CAGR-Based Forecasting
- Investment Classification Systems
- Interactive Dashboard Development

---

# 🎯 Problem Statement

Evaluating real estate investments manually can be:
- Time-consuming
- Data-intensive
- Difficult to analyze accurately
- Challenging for future forecasting

Real Estate Investment Advisor solves this problem by:
✅ Automating property investment analysis  
✅ Predicting future property prices  
✅ Generating investment quality scores  
✅ Providing market trend insights

# 🔥 Key Features

## 📊 Exploratory Data Analysis (EDA)
Perform visual and statistical analysis on real estate datasets.

---

## 🧠 Financial Feature Engineering
Generate investment-related metrics such as:
- Price per Sqft
- Appreciation Rate
- Investment Score
- Location-based valuation

---

## 📈 5-Year Price Forecasting
Predict future property prices using CAGR-based forecasting models.

---

## 🏷️ Investment Classification System
Classify properties into:
- Buy
- Hold
- Avoid

based on investment quality metrics.

---

## 🌐 Interactive Streamlit Dashboard
Clean and interactive analytics dashboard for property analysis.

---

## 📉 Visual Market Insights
Generate charts and visualizations for trend analysis.

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/vamsimeenan/real-estate-investment-advisor.git
```

---

## 2️⃣ Navigate to Project

```bash
cd real-estate-investment-advisor
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Streamlit Application

```bash
streamlit run app.py
```
